# Contributing

This is a first-game learning project. Useful contributions help us make the game better while keeping the work understandable and small.

## Before starting

Read the [vision](docs/vision.md), [roadmap](docs/roadmap.md), and [workflow](docs/workflow.md). For a substantial feature or new dependency, open an issue describing the player benefit and proposed scope before implementation.

## Submitting a change

1. Keep the change focused on one improvement or question.
2. Explain the behavior before and after the change.
3. Describe how you verified it; include controls or reproduction steps for gameplay changes.
4. Update setup instructions, design notes, or credits when affected.
5. Note remaining limitations and any relevant AI assistance or external material.

Do not commit secrets, generated builds, or assets with unknown provenance. A license for the project has not yet been selected; do not assume this repository grants reuse rights.

Bug reports are most useful with the build/commit, platform, steps to reproduce, expected behavior, and actual behavior. A screenshot or clip can help when the issue concerns timing or visual feedback.
