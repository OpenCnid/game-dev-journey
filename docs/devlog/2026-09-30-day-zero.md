# Day zero: learning to make a game

**Date:** 2026-09-30

We're starting with software engineering experience and no finished games. The aim is to learn game development by making something small enough to finish, with AI and LLMs as collaborators along the way.

The motivation is a personal shift in confidence: this feels approachable now in a way it didn't a few years ago. We have not tested that belief with a game yet. This repository will hold the evidence as we go.

## What we established

- A place for the eventual game, separate from throwaway experiments.
- A vision and a milestone-based roadmap.
- Lightweight places to capture design, decisions, and playtest observations.
- A workflow that includes reading AI-generated changes and verifying them through execution and play.

## What we have not decided

The concept, engine, programming language, platform, visual style, and release destination are all still open. There is no playable build yet.

## Next step

Write three tiny ideas, pick one main interaction to explore, and choose tools for its first prototype.
