# Game design document: chapter map

This is the GDD entry point. [The foundation](../foundation.md) owns the accepted vision; the chapters below hold detailed rules and their reasoning. This map organizes existing material and exposes gaps. It does not approve open mechanics or declare the GDD finished. Use the [documentation contract](../documentation.md) when adding or revising a chapter.

## Next design conversation

Describe one representative run from the player's perspective using the accepted fantasy and loop. Identify where a creative decision is missing and offer a small number of concrete options with tradeoffs. Record the owner's selection, leave unanswered details explicit and use the result to connect these chapters before choosing another feature. The owner directs the experience; the AI maintains the detail and trace links.
