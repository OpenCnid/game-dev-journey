# Permanent progression matrix exploration

**Parked idea — beyond MVP/alpha, extremely low priority.** The owner deferred further matrix development on October 3, 2026 because of its scope. [GDJ-9](https://linear.app/cnid/issue/GDJ-9/idea-permanent-progression-matrix) preserves the idea; Linear owns its live priority/status. The sections below retain possibilities for later review, not current work or an implementation commitment. Persistent discoveries remain a future direction; a full matrix, permanent-power system and pool-preparation economy are outside MVP/alpha scope.

GDJ-6 discussion, October 3, 2026. [Decision 0007](../decisions/0007-roguelike-run-identity-and-camera-exploration.md) records the owner's roguelike/roguelite identity and accepted weapon/upgrade discoveries across runs. The owner asked to understand this more deeply and explore permanent power through a branching matrix, citing tower-defense progression and Path of Exile's leveling tree. The matrix and all specific nodes below are proposals, not implemented or accepted content.

## Three kinds of growth

| Layer | Purpose | Status |
| --- | --- | --- |
| Earned run build | Shared XP and personal choices grow the current arsenal, with selected qualifying rares granted to the team | Accepted; exact reset/lifecycle rules remain open |
| Persistent discoveries | Unlock new weapons/upgrades to discover in future runs | Accepted direction; conditions, ownership and availability rules remain open |
| Permanent preparation or power | Plan future draws/loot, specialize a starting setup or increase baseline capability | Proposed; no permanent numerical boost, currency or node rule selected |

A discovered weapon being available is a different event from receiving it in a run. The recommended default is that discoveries expand what can be offered while earned choices still produce the run's build. Whether a discovery also becomes a selectable starting gun is open; preserve the accepted one-gun start.

## A possible matrix

Use a small web of connected choices with meaningful branches and occasional hybrid connections. [Path of Exile's official tree description](https://www.pathofexile.com/passive-skill-tree) supplies the connected-node inspiration; its exact rules are not ours. A few understandable paths can establish the design before a large tree is authored.

| Example node family | Possible effect | Design question |
| --- | --- | --- |
| Discoveries | Make an authored technological, magical or qi weapon/upgrade available in later runs | What earns the unlock, and how does it enter an individual player's catalog/pool? |
| Pool preparation | Choose a theme or adjust future offer availability/weights | Can players pursue a build without removing meaningful randomness or making new unlocks dilute it? |
| Loot research | Change a defined loot outcome or magic-find behavior | Which event is affected, at what point, and how does it compose with run-earned modifiers? |
| Permanent capacity/mastery | Start with more capacity or a specialized expression | Is this desirable permanent power, and how can newer friends remain useful? |

These node families could appear within technology, magic and cultivation branches, with authored hybrid links. That is a proposal for the map's organization, not permanent exclusive classes or a ban on mixing early builds. Capacity/mastery is already an accepted weapon-growth framework in [decision 0006](../decisions/0006-capacity-mastery-and-prepared-power.md); making either persist between runs is an additional open decision.

One model to compare: permanent progress unlocks more matrix options, and every player selects effects within a common active-node budget before a run. Long-term progression expands available paths; the budget bounds how much permanent preparation/power is active together. This could support veteran/new-friend parties, but equal budgets do not prove equal usefulness. Budget size, node costs, respecs, acquisition and whether discoveries consume that budget are all unselected.

## Co-op and draw-pool interactions

- **Veterans and new friends:** shared XP aligns run opportunities but does not erase differences in permanent starting power. Permanent unlocks can also give experienced players better options. Evaluate contribution and choices in mixed-progression parties before adopting unlimited passive stat growth.
- **Pool expansion:** automatically adding every discovery to the pool could reduce the frequency of a desired offer, depending on weights and eligibility rules. Opt-in themes, active subsets or focused preparation are alternatives to investigate; none is selected.
- **Personal ownership and shared rares:** decide whether teammates can temporarily receive a selected rare they have not permanently unlocked, and whether receiving it advances a persistent discovery. A run grant must not silently become an account unlock.
- **Ordering:** keep catalog discovery, run eligibility, offer generation, selected effects and permanent changes distinct. A persistent pool modifier and a run-earned modifier need an explicit combination rule, including protection for already revealed offers. Exact formulas/schema are open.
- **Readable expansion:** new branches should introduce distinct choices rather than obligatory stat taxes. Costs, prerequisites, respecs, active-node budgets and how content is extended remain to define. Preserve safe thinking-space access for every party.

## If revisited after MVP/alpha

Compare an experienced player's discoveries with a newer friend's options in one example run. First model availability-only unlocks, then add one proposed pool-shaping choice and one proposed permanent-power effect. Explain what each player can start with, earn, draw and share; identify changes to contribution without inventing fun/fairness scores. Select persistence and budget rules with the owner before implementation.

The inline matrix sketch illustrates selecting draft paths and distinguishing their consequences. It has no game economy, balance values, real save data or implementation. Exact run-reset behavior and a permanent-power expansion remain open.
