# Prototypes

Each experiment gets a descriptive subfolder such as `001-movement-feel/`. Name it after the question or mechanic being explored.

Before implementation, add a short README covering:

- **Question:** what uncertainty are we testing?
- **Tools:** engine/runtime and exact version, once chosen.
- **Run:** how to launch the experiment.
- **Boundary:** the smallest scope and stopping condition.
- **Result:** what did playing it teach us?
- **Disposition:** continue, revise, discard, or promote into `game/`.

Prototypes may use rough code and placeholder assets. They still need enough instructions to run again. Avoid sharing code between experiments until a real need appears.
